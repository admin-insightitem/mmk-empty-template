# Slack으로 증시 요약 알림 전송

한국 증시 YouTube 영상 요약을 Slack 채널에 전송합니다.

## 입력

$ARGUMENTS

- 인자로 전송할 요약 텍스트를 받습니다.
- 인자가 없으면 사용자에게 전송할 내용을 요청하세요.

## 실행 단계

### 1. Slack 채널 찾기
Slack MCP 도구를 사용하여 적절한 채널을 검색합니다:
- `slack_search_channels` 도구로 "stock", "주식", "증시" 등의 키워드로 채널을 검색합니다.
- 적절한 채널을 찾지 못하면 사용자에게 채널명을 물어봅니다.
- 채널의 `channel_id`를 기억합니다.

### 2. 메시지 포맷팅
Slack 메시지를 아래 형식으로 구성합니다:

```
📊 *한국 증시 유튜브 요약*

*[채널명] 영상 제목*
🔗 <영상링크|YouTube에서 보기>
📅 게시일

*핵심 요약*
요약 내용

*주요 내용*
• 포인트 1
• 포인트 2
• 포인트 3

*언급된 종목/지표*
종목 목록

*시장 전망*
전망 내용

---
🕐 자동 요약 | {현재 날짜 및 시간}
```

### 3. 메시지 전송
`slack_send_message` MCP 도구를 사용하여 메시지를 전송합니다:
- `channel_id`: 검색한 채널 ID
- `message`: 포맷팅된 메시지 텍스트

### 4. 결과 보고
전송 성공/실패 여부를 사용자에게 알려주세요.
- 성공 시: "Slack #{채널명}에 요약을 전송했습니다."
- 실패 시: 에러 내용과 함께 보고
